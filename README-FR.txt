BUSINESSFLOW — prototype installable (PWA)
==========================================

CE QUE CONTIENT LE DOSSIER
- index.html : l'application de démonstration
- manifest.webmanifest : informations d'installation
- sw.js : cache hors-ligne simple
- icon-192.png et icon-512.png : icônes

TESTER
1. Décompressez le ZIP sur un ordinateur.
2. Pour tester correctement l'installation PWA, publiez le contenu du dossier sur un hébergement HTTPS.
3. Ouvrez l'adresse HTTPS dans Safari sur iPhone.
4. Dans Safari : bouton Partager > Sur l'écran d'accueil > Ajouter.

IMPORTANT
Ce prototype est une démonstration locale. Les données sont enregistrées uniquement dans le navigateur de l'appareil.
Ne saisissez pas de vraies données personnelles ou commerciales.
Il n'y a pas de comptes sécurisés, de base de données distante, de sauvegarde, de facturation réelle, ni de paiement par abonnement.
Il ne s'agit pas encore d'une application prête pour des clients ou pour l'App Store.

POUR PUBLIER SUR L'APP STORE
1. Transformer ce prototype en vraie application iOS (par exemple avec un projet Xcode).
2. Ajouter un serveur et une base de données sécurisés, des comptes, une séparation stricte des entreprises, des sauvegardes et une gestion des droits.
3. Préparer les mentions légales, politique de confidentialité, informations de collecte de données et tests.
4. Créer une fiche App Store (nom, description, captures d'écran, catégorie, classification d'âge).
5. Soumettre l'application à Apple pour examen depuis App Store Connect.

COMPTE APPLE
La publication nécessite l'inscription au programme Apple Developer, généralement 99 USD par an.
Comme le créateur est mineur, un parent ou représentant légal devra prendre en charge les démarches contractuelles et le compte lorsque les conditions d'Apple l'exigent. Ne contournez pas les conditions d'âge.

Le prototype est un point de départ technique, pas une garantie d'acceptation par Apple.
